# LumaLearn

LumaLearn is a web-based learning assistant designed to help students study different subjects through structured lessons, examples, practice questions, and interactive quizzes.

## Features

- Structured lessons
- Examples and practice questions
- Interactive multiple-choice quizzes
- Automatic quiz grading
- Explanations for answers
- Support for Mathematics, Physics, Biology, and History
- Responsive web design

## Technologies

- Next.js
- TypeScript
- React
- Tailwind CSS

## Live Website

https://lumalearning.vercel.app

## Purpose

LumaLearn was created as a personal project to explore web development, educational technology, and software engineering.

## Future Improvements

- Integration with a real AI provider
- User accounts
- Cloud-based progress tracking
- More subjects and educational content
